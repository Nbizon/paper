\section{Background and Motivation}
\label{sec:background}

\begin{itemize}[leftmargin=*]
    \item Position this section as a future ``Background and Related Work'' block that is shorter and denser.
    \item Contrast two evaluation styles:
    \begin{itemize}[leftmargin=*]
        \item macroscopic benchmarks, which are closer to realistic tasks but less diagnostic;
        \item controlled tasks, which are less realistic but better suited to isolating a precise capability.
    \end{itemize}
    \item Defend the idea that a microscopic synthetic task can still be scientifically useful if it is:
    \begin{itemize}[leftmargin=*]
        \item simple to define;
        \item experimentally controlled;
        \item connected to a fundamental program-understanding capability;
        \item paired with an exact oracle.
    \end{itemize}
    \item Motivate reachability specifically:
    \begin{itemize}[leftmargin=*]
        \item for control flow, it captures path following in a call graph;
        \item for data flow, it captures path following when calls may be guarded by conditions over generated variables.
    \end{itemize}
    \item Clarify the ambition:
    \begin{itemize}[leftmargin=*]
        \item the benchmark does not replace real-repository benchmarks;
        \item it serves as a diagnostic probe for a more fundamental structural capability.
    \end{itemize}
    \item Definitions to stabilize in the final version:
    \begin{itemize}[leftmargin=*]
        \item control-flow reachability ;
        \item data-flow reachability ;
        \item source method ;
        \item target method ;
        \item trace ;
        \item chain ;
        \item depth ;
        \item distance ;
        \item positive case ;
        \item negative case.
    \end{itemize}
\end{itemize}
