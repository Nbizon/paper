\section{Conclusion}
\label{sec:conclusion}

In this paper, we present \benchmark, a generated Java dataset for questions about whether a target method executes from a source under concrete values. Its configurable parameters vary class size, guarded calls, and values passed between methods. This allows us to compare model behavior across structural difficulties. Execution validates the labels and graphs on the complete dataset. The evaluator scores the Boolean answer and method trace separately. Checking the trace against the executable graph shows whether the explored methods follow calls that can execute.

The results show that a correct answer can come with an incomplete trace or with calls that cannot execute. The trace provides information about the program behavior supporting the answer. The main difficulties involve guarded calls, passed values, and the complete exploration required by negative questions. Comparing CO and EE also shows that models can behave differently on the same dataset when the execution context is made explicit. The gains remain modest for Gemma and Qwen3.6. Qwen3.8-Flash-Next improves its traces more on the difficult subset, but also produces more non-responses.

By evaluating decisions and traces separately, we can identify difficulties that final-answer correctness alone does not reveal. Further evaluation on more models and real programs would make it possible to examine how broadly these difficulties transfer.
