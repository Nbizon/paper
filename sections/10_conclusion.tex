\section{Conclusion}
\label{sec:conclusion}

\begin{itemize}[leftmargin=*]
    \item Restate the final paper in one line: a controlled Java reachability benchmark for evaluating structural reasoning in LLMs on control-flow and data-flow tasks.
    \item Restate the methodological message:
    \begin{itemize}[leftmargin=*]
        \item macroscopic evaluations are not sufficient to isolate structural reasoning;
        \item a controlled reachability task with an exact oracle is useful as a diagnostic probe;
        \item path-level and trace-level evidence should be reported.
    \end{itemize}
    \item Close with the next steps:
    \begin{itemize}[leftmargin=*]
        \item finalize the specification of the data-flow family;
        \item finalize the baselines and statistics;
        \item run the reasoning-vs-non-reasoning comparison;
        \item release the anonymized artifact;
        \item rewrite the final paper from complete results rather than from the budget-only preliminary study.
    \end{itemize}
\end{itemize}
