\section{Threats to Validity}
\label{sec:threats}

\subsection{Internal Validity}

\begin{itemize}[leftmargin=*]
    \item Parsing and normalization may under-credit or over-credit some outputs.
    \item Alignment to the oracle is sensitive, especially for negative cases.
\end{itemize}

\subsection{Construct Validity}

\begin{itemize}[leftmargin=*]
    \item Trace correctness is only a proxy for reasoning quality.
    \item This proxy still matters because visible traces are what users inspect.
    \item Emitted reasoning length is not an internal reasoning cost.
\end{itemize}

\subsection{External Validity}

\begin{itemize}[leftmargin=*]
    \item Synthetic Java improves control but reduces realism.
    \item Missing real-world features to mention:
    \begin{itemize}[leftmargin=*]
        \item inheritance;
        \item dynamic dispatch;
        \item exceptions;
        \item concurrency;
        \item reflection;
        \item library and build structure.
    \end{itemize}
\end{itemize}

\subsection{Conclusion Validity}

\begin{itemize}[leftmargin=*]
    \item Filtering to a shared slice improves fairness but narrows the claims.
    \item Contrasts across factors are descriptive rather than causal.
    \item Rapid changes in models and serving stacks reduce temporal stability.
\end{itemize}

\subsection{Transparency, Ethics, and Artifact Availability}

\begin{itemize}[leftmargin=*]
    \item No human participants are involved.
    \item Still document:
    \begin{itemize}[leftmargin=*]
        \item model licenses;
        \item compute cost;
        \item hardware requirements;
        \item artifact release constraints.
    \end{itemize}
\end{itemize}
