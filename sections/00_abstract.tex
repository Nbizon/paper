Realistic benchmarks for large language models in software engineering are essential for measuring end-to-end usefulness, but their aggregate scores often entangle localization, API knowledge, editing skill, test feedback, naming cues, and program-structure reasoning. Diagnostic progress requires complementary benchmarks that control the program structure and expose why a model succeeds or fails. We introduce \benchmark, an oracle-supervised Java benchmark for executable inter-method reachability in generated single-class programs. The benchmark controls canonical trace length, class size, query polarity, and condition-aware guards, enabling factor-level analysis of structural difficulty. Its trace-aware evaluation distinguishes syntactic call visibility from executable reachability and measures final-answer accuracy, exact canonical trace accuracy, trace completeness, graph-valid exploration, syntactic-call bias, and invalid-output behavior.
