\begin{itemize}[leftmargin=*]
    \item Problem: current LLM evaluations often measure whether the final answer is correct on macroscopic problems, but they isolate structural reasoning over code poorly.
    \item Target artifact: \benchmark as a controlled Java reachability benchmark with two task families, control-flow and data-flow.
    \item Shared principle: a reachability question, a structured output, an exact oracle, and an explanatory trace.
    \item Methodological value: the task is easy to define, supports clean synthetic generation, allows automatic verification, and exposes controlled difficulty.
    \item Final experimental program: compare models, measure their performance, and then analyze the effect of dataset-intrinsic parameters.
\end{itemize}
