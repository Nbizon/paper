\section{Methodology}
\label{sec:methodology}

\subsection{Experimental Scope}

\begin{itemize}[leftmargin=*]
    \item The final paper should cover two families:
    \begin{itemize}[leftmargin=*]
        \item control-flow reachability ;
        \item data-flow reachability.
    \end{itemize}
    \item Each case contains at minimum:
    \begin{itemize}[leftmargin=*]
        \item a generated Java class;
        \item a source-target question;
        \item an oracle label;
        \item an oracle trace;
        \item generation metadata.
    \end{itemize}
    \item Current experimental status:
    \begin{itemize}[leftmargin=*]
        \item only the control-flow experiments have been run so far;
        \item the full reasoning-vs-non-reasoning and control-flow-vs-data-flow analyses still remain to be done.
    \end{itemize}
    \item The shared slice already used for the preliminary study is:
    \begin{itemize}[leftmargin=*]
        \item contexts 100, 250, and 500;
        \item depths 1 to 25;
        \item budgets 512 to 16\,384.
    \end{itemize}
\end{itemize}

\subsection{Models and Inference}

\begin{itemize}[leftmargin=*]
    \item The final paper should compare:
    \begin{itemize}[leftmargin=*]
        \item reasoning models;
        \item non-reasoning models;
        \item a static baseline;
        \item a heuristic baseline.
    \end{itemize}
    \item The same program, question, and output schema are used within a given task family.
    \item The requested reasoning budget is a relevant variable only for models that expose this control.
    \item The target decoding setup is deterministic or near-deterministic.
    \item The three models currently included correspond to the preliminary empirical material already available.
\end{itemize}

\subsection{Metrics}

\begin{itemize}[leftmargin=*]
    \item The evaluator parses:
    \begin{itemize}[leftmargin=*]
        \item the final answer;
        \item the trace.
    \end{itemize}
    \item Metrics to report:
    \begin{itemize}[leftmargin=*]
        \item final-answer accuracy ;
        \item chain accuracy ;
        \item trace accuracy ;
        \item trace completeness ;
        \item emitted reasoning length.
    \end{itemize}
    \item Metrics should remain consistent across control-flow and data-flow because both families use the same reachability question and trace format.
    \item Important caveat:
    \begin{itemize}[leftmargin=*]
        \item emitted reasoning length is only a visible-text proxy;
        \item it is not an internal measure of reasoning tokens.
    \end{itemize}
\end{itemize}

\subsection{Aggregation and Analysis}

\begin{itemize}[leftmargin=*]
    \item Aggregate over shared slices when cross-model comparison requires it.
    \item Break results down by:
    \begin{itemize}[leftmargin=*]
        \item model;
        \item task family;
        \item context size ;
        \item depth ;
        \item requested reasoning budget ;
        \item code-level factors.
    \end{itemize}
    \item For \researchq{1}: compare overall performance across model families and task families.
    \item For \researchq{2}: quantify the effect of structural factors.
    \item For \researchq{3}: compare control flow and data flow at comparable difficulty.
    \item For \researchq{4}: compare reasoning and non-reasoning models, then compare performance across requested reasoning budgets and identify saturation for models that expose this control.
\end{itemize}
