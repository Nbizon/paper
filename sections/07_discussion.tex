\section{Error Analysis}
\label{sec:error-analysis}

Beyond aggregate metrics, we conduct a semi-quantitative error analysis using an interactive deeper-analysis dashboard. The dashboard groups trace failures by structural parameters, reasoning budget, and local graph motifs. We use it to identify recurrent error families, such as syntactic-call bias in condition-aware instances, where models follow visible but non-executable calls. These error-family counts complement the main metrics by explaining why performance degrades when reachability depends on conditions.
